# PhysioGhar — Therapist App

A Flutter prototype of the PhysioGhar therapist app: daily dashboard, weekly schedule and
availability, booking requests and session management, patient records with session notes,
profile, and issue reporting.

Android only. All data is mocked locally.

## Running

```
flutter pub get
flutter run
```

## Versions

Flutter 3.44.1 (stable) · Dart 3.12.1
